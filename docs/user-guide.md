## 快速开始

### 1. 系统登录

1. 打开浏览器，访问系统地址
2. 输入学号和密码登录
3. 首次登录后建议修改密码

账号由管理员统一录入，系统不开放自助注册。管理员录入正式成员后，系统会向该成员的邮箱发送激活邮件，成员点击邮件中的链接设置密码，账号方可使用。

### 2. 完善个人信息

1. 进入"我的权限"，查看自己的部门与角色
2. 确认姓名、邮箱等信息正确
3. 如部门信息有误，联系管理员修改

### 3. 录入无课表

1. 进入"无课表"页面
2. 点击任意时段格子，在弹窗中勾选该时段无课的周次
3. 绿色表示无课（可排班），红色表示有课
4. 点击"保存"按钮保存

## 电脑端与手机端

| 项目 | 电脑端 | 手机端 |
|------|--------|--------|
| 访问地址 | 系统根地址 | 系统根地址下的 `/mobile/` |

手机端通过浏览器访问，页面会自适应手机屏幕。

## 首页概览

登录后进入首页，可以看到：

### 本周排班

- 显示当前周的值班安排
- 包含星期、节次、值班人员
- 电脑端展示每个时段的完成度进度条，手机端以圆点颜色标识完成情况（已完成 / 部分完成 / 未完成）

### 快速操作

首页提供快捷入口，按角色显示：

- **录入无课表** - 跳转到无课表页面
- **我的值班** - 查看自己的值班安排
- **排班结果** - 查看所有排班
- **排班管理** - 管理排班（部门管理员及以上）
- **每周分工** - 管理部门分工安排（办公室管理员及以上）

### 个人信息卡片

- 显示姓名、学号、部门
- 当前周次
- 系统角色和部门角色

### 设置周次

系统管理员可在首页点击"设置周次"，调整当前周次以及是否在确认排班后自动递增到下一周。

## 个人设置

### 修改密码

1. 进入个人设置（电脑端：顶部用户名菜单 → "修改密码"；手机端："我的" → "修改密码"）
2. 输入原密码
3. 输入新密码（6-20位）
4. 确认新密码
5. 点击"保存"

### 查看我的权限

1. 进入"我的权限"页面
2. 查看当前系统角色、部门角色和拥有的权限
3. 查看临时权限详情及有效期（如有）

### 退出登录

电脑端在顶部用户名菜单中退出；手机端在"我的"页面底部点击"退出登录"。

## 无课表管理

无课表是排班的基础数据，用于记录您的空闲时间。表格覆盖周一至周五，共四个大节：第一二节、第三四节、第五六节、第七八节。

### 手动录入

1. 进入"无课表"页面
2. 表格按节次与星期排列
3. 点击格子打开编辑弹窗
4. 在弹窗中勾选该时段无课的周次（可多选）
5. 点击"保存"提交；如需清空该时段全部记录，点击"全部清空"

手机端可先通过顶部的周次下拉菜单切换查看的周次。

### 教务系统导入

1. 进入"无课表"页面，点击"教务系统导入"
2. 按提示完成教务系统登录
3. 系统自动抓取课程表并转换为无课表

### XLS 导入

1. 点击"XLS导入"按钮
2. 上传课程表文件，支持 `.xls` 和 `.xlsx` 格式
3. 文件需包含以下列：课程名、教师、周次、节次、星期、教室
4. 系统解析并转换为无课表，完成后显示导入结果

## 排班管理

> **注意**: 此功能需要排班管理权限

### 排班参数

在排班管理页面顶部可以设置：

- **当前周次** - 首页默认显示的周次
- **每时段人数** - 默认值班人数
- **每时段最少** - 低于此人数会提示
- **每人每天最多** - 防止一天排太多次
- **每人每周最多** - 平衡工作量

修改后点击"保存"。

### 查看本周分工

排班管理页面会显示当前周本部门的分工安排，可点击"应用分工日期"直接将分工中的值班日期填入生成排班表单。

### 生成排班

1. 进入"排班管理"页面
2. 在"生成排班"区域配置：
   - **周次** - 选择要排班的周次
   - **部门** - 选择排班部门（部门管理员锁定为本部门）
   - **星期** - 勾选需要值班的星期
   - **节次** - 选择每天的值班节数
3. 点击"生成预览"

### 预览和调整

1. 系统根据无课表自动生成排班方案
2. 在预览表格中查看分配结果
3. 如需调整：
   - 点击已排人员标签右上角的关闭按钮将其移除
   - 点击"+ 添加"按钮，从可选人员中选择加入
4. 系统会提示人数不足的时段
5. 确认无误后点击"确认排班"

### 导出模板配置

排班结果支持按模板导出为 Excel，可新建、编辑多个模板：

- **导出格式** - 列表格式（每行一个时段）或课表格式（矩阵表格）
- **表格标题** - 支持占位符 `{week}`（周次）、`{department}`（部门）
- **列表格式** - 自定义表头与数据列，数据列支持星期、节次、值班人员、固定文本
- **课表格式** - 自定义行标题、列标题及行/列标签

配置后可在"选择模板"下拉中选用，并点击"预览效果"查看导出样式。默认模板不可删除。

## 值班管理

### 查看我的值班

1. 点击"我的值班"菜单（手机端在"我的排班"标签页或"我的" → 我的值班）
2. 查看自己的值班安排
3. 包含周次、星期、节次、状态

### 值班状态

- **待确认** - 刚安排的值班，等待您确认
- **已确认** - 已确认参加值班
- **已完成** - 值班已完成
- **已取消** - 请假或取消值班

值班状态的确认、请假等操作功能正在开发中。

## 用户管理

> **注意**: 此功能需要用户管理权限。办公室管理员与系统管理员可管理全部用户，部门管理员管理本部门用户。

### 查看用户列表

1. 进入"用户管理"页面
2. 查看用户信息，可按状态筛选：全部 / 待入职 / 在职 / 离职

### 录入正式成员

1. 点击"录入正式成员"
2. 支持两种方式：
   - **单个录入** - 填写姓名、学号、部门、部门角色、邮箱
   - **批量录入** - 每行一条，格式为 `学号,姓名,部门,邮箱`，支持逗号分隔的文本或 CSV
3. 提交后系统自动向成员邮箱发送激活邮件，由成员自行设置密码，无需在此设置密码

成员账号状态分为三态：

- **待入职** - 已录入、等待成员通过邮件激活
- **在职** - 已激活、可正常使用
- **离职** - 已离职，不可登录

### 管理待入职账号

对处于"待入职"状态的成员，可以：

- **重发邀请** - 重新发送激活邮件
- **作废** - 作废该邀请，账号不可激活

### 编辑用户

1. 在用户列表找到目标用户，点击"编辑"
2. 可修改姓名、邮箱
3. 管理员可额外修改部门、系统角色、部门角色
4. 确认保存

> 提示：办公室管理员请选择部门为"办公室"并开启部门管理员。

### 离职处理

1. 在用户列表点击"离职"，或勾选多名成员后点击"批量离职"
2. 系统展示受影响的待处理排班数与临时权限数
3. 确认后，成员被标记为离职，不可登录、不可再次注册，其待处理排班被取消、临时权限失效
4. 批量离职时，可取消勾选个别成员以保留其在职状态

## 临时权限与权限申请

### 权限申请（普通用户）

> **说明**: 普通用户可以主动申请临时权限，经管理员审批后获得

#### 申请权限流程

1. **进入权限申请页面**
   - 点击导航栏"权限申请"，或在"我的权限"中进入

2. **填写申请信息**
   - **申请类型** - 临时权限 或 请假
   - 申请临时权限时：**选择权限**、**期望到期日**（留空表示永久有效）
   - 申请请假时：**请假类型**（病假/事假/年假）、**开始日期**、**结束日期**
   - **申请原因** - 详细说明申请理由和使用场景

3. **提交申请**
   - 点击"提交申请"按钮
   - 申请单号生成，等待审批

4. **查看申请状态**
   - 在"我的申请"标签页查看所有申请记录，可点击"详情"查看申请详情
   - 状态说明：
     - 待审批 - 等待管理员审批
     - 已通过 - 权限已授予
     - 已拒绝 - 申请被拒绝
     - 已撤回 - 已取消申请

5. **使用临时权限**
   - 审批通过后，权限自动生效
   - 在"我的权限"页面查看有效权限
   - 权限过期后自动失效

> 申请全局权限时会发送给办公室管理员或系统管理员审批，其余申请发送给本部门管理员审批。

#### 取消申请

如果申请尚未审批，可以撤销：

1. 在"我的申请"中找到待审批的申请
2. 点击"撤销"按钮
3. 确认取消

---

### 权限审批（部门管理员）

> **注意**: 此功能需要对申请所需权限的审批权

#### 审批申请流程

1. **查看待审批申请**
   - 进入"权限申请"页面
   - 切换到"待我审批"标签页
   - 查看待处理的权限申请

2. **处理申请**
   - 点击"通过"按钮批准申请
   - 或点击"拒绝"按钮拒绝申请
   - 填写审批意见（拒绝时需填写原因）

3. **审批后效果**
   - 通过后：申请人自动获得临时权限
   - 拒绝后：申请被拒绝

---

### 直接授予权限（管理员）

> **注意**: 此功能需要授予权限的权限

#### 授予临时权限

1. 进入"权限申请"页面，切换到"权限管理"标签页
2. 点击"授予权限"按钮
3. 在表单填写：
   - **选择用户** - 被授予权限的用户，支持按姓名或学号搜索、可多选
   - **权限类型** - 要授予的权限
   - **到期日期** - 权限失效时间（留空表示永久有效）
   - **授权原因** - 授权原因（可选）
4. 点击"确定授权"

授予权限时，被授予的权限必须包含在您自身的权限范围内。

#### 权限说明

| 权限 | 说明 | 适用场景 |
|------|------|----------|
| 排班管理（全部） | 管理所有部门排班 | 统筹协调 |
| 排班管理（部门） | 管理本部门排班 | 部门管理 |
| 用户管理（全部） | 管理所有用户 | 人事管理 |
| 用户管理（部门） | 管理本部门用户 | 部门管理 |
| 设置每周分工 | 设置各部门值班日期 | 统筹协调 |

#### 撤销权限

1. 在权限管理列表找到要撤销的权限
2. 点击"撤销"按钮
3. 确认撤销

## 学期设置

> **注意**: 此功能需要管理全部部门的权限

1. 进入"学期设置"页面
2. 设置**学期起始日**（本学期第一周的周一日期）
3. 系统根据学期起始日与当前日期自动计算当前周次
4. 点击"保存设置"；也可点击"重新计算周次"更新

页面提供"今年秋季学期""今年春季学期"快捷设置按钮。

## 邮件配置

## 系统更新

> **注意**: 此功能需要系统管理权限

1. 进入「系统管理 / 系统更新」页面；
2. 点击「检查更新」，系统查询是否存在同大版本且版本号更高的发布；
3. 点击「下载更新包」开始下载。下载期间系统正常提供服务，可随时点击「取消下载」中止；
4. 下载完成并通过校验后，「安装更新」按钮可用。点击后系统停机安装，期间访问 8080 端口会显示安装进度页；安装失败会自动回滚到旧版本；
5. 下载缓慢时，可在「镜像加速」区添加镜像地址并保存，下次下载生效。镜像仅加速安装包下载，版本信息与校验值始终来自官方源。

大版本更新可能包含数据库结构变更，无法通过热更新完成，需手动下载整包并按发布说明迁移。

## 常见问题

### Q1: 无法登录怎么办？

**可能原因**:

- 学号或密码错误
- 该学号未录入，请联系管理员录入正式成员
- 账号待激活，请查收激活邮件完成激活
- 账号已离职

**解决方法**:

1. 检查学号和密码
2. 如忘记密码，通过登录页"忘记密码"重置，或联系管理员
3. 未收到激活邮件，请联系管理员重发邀请

### Q2: 忘记密码怎么办？

1. 在登录页面点击"忘记密码"
2. 输入学号
3. 系统向您的注册邮箱发送重置链接（需管理员已配置邮件服务）
4. 点击邮件中的链接设置新密码

### Q3: 无课表导入失败？

**可能原因**:

- 教务系统账号登录失败
- 教务系统改版
- 网络问题
- 上传的表格缺少必需列

**解决方法**:

1. 重新登录教务系统
2. 检查网络连接
3. 检查表格是否包含课程名、教师、周次、节次、星期、教室等列
4. 尝试手动录入

### Q4: 排班时提示"人数不足"？

**可能原因**:

- 部门成员未录入无课表
- 约束条件太严格

**解决方法**:

1. 提醒部门成员录入无课表
2. 放宽约束条件（如增加每时段人数）
3. 减少排班天数
4. 在预览中手动添加人员

### Q5: 为什么看不到管理菜单？

**可能原因**:

- 没有管理权限
- 临时权限已过期

**解决方法**:

1. 查看"我的权限"确认权限状态
2. 联系管理员申请权限

### Q6: 如何修改部门？

部门信息只能由管理员修改：

1. 联系部门管理员或办公室管理员
2. 提供需要修改的部门信息
3. 管理员在"用户管理"中修改

### Q7: 值班时间冲突怎么办？

1. 联系排班管理员说明情况
2. 管理员可以在"排班管理"中调整
3. 或安排其他人员代班
