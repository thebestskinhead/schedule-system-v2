# 当前周次与候选值班人

当前周次统一由后端计算，首页、排班管理、排班结果、无课表、每周分工和学期设置共用同一个结果。电脑端与移动端排班管理默认选择当前周。

周次始终随日期自动递增，按北京时间的日期计算，范围为第 1–30 周。设置学期起始日后，每满七天进入下一周；没有设置起始日时，以周一为周界。手动设置当前周次会保存当前周的起算日期，立即生效，并在后续周继续递增，不修改学期起始日及课表、请假所依赖的日期。确认排班不会推进当前周。重新保存学期起始日会清除手动校准，恢复按该起始日计算。

后端启动与安装时会自动补充 `current_week_set_at` 字段，并将旧配置的自动递增设为开启。也可单独执行 `backend/migrations/015_fix_current_week.sql`。`auto_increment` 响应字段为兼容旧客户端保留，始终返回 `true`，旧客户端传入的关闭值不再生效。

排班预览中的“添加”会查询所选部门的在职成员（排除部门管理员），列出每人的当日次数、本周次数及可添加状态。不符合条件时显示原因并禁用选择：该时段有课或没有无课记录、已请假、已添加，或已达到日/周最大排班次数。未填报无课时间时不会推断为无课。

次数按当前整张草稿计算，与自动排班一致；因为确认操作会替换该周旧排班，不会把旧记录重复累计。删除草稿中的人员后，其名额立即释放，下次打开添加窗口会重新计算。点击添加及最终确认时都会重新校验，避免只在前端判断。提交时同时携带页面当前的日、周上限；旧客户端未携带时使用已保存的设置。

验证覆盖：北京时间跨周、手动校准及继续递增、第 30 周上限、日/周次数限制、无课记录缺失、重复添加、删除后释放名额，以及空时段添加结果在确认和导出数据中保留。
