2. `sp_activate_invitation`：改先取 `student_id` 入变量再 UPDATE，修正 1093（原稿 subquery 引用未定义别名 `inv`）。
3. `evt_cleanup_expired`：采用 §12.4.6 分批 `LIMIT 1000` 循环（§8 无 LIMIT，取更严格分批版）。
4. `schedule_settings` 单例：保留最小 id 行 + `INSERT IGNORE 'global'`，契合 §11/§7.1 单例行 `FOR UPDATE` 锁。
